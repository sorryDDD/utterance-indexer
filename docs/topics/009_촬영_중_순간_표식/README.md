# 009 · 촬영 중 순간 표식

- **상태**: 열림

## 질문

회기를 촬영하는 동안 임상가가 나중에 다시 볼 순간을 무엇으로 표시할 것인가.

이 스레드는 녹음 조건 전체가 아니라 촬영 중 사람이 남기는 표식만 다룬다. 두 기기의 시각 동기는 별개의 용도다.

## 관련 결정

없다.

## 남은 질문

- 임상가가 회기 중 감당할 수 있는 표시 빈도와 조작 형태는 작업지시자의 임상 판단이 필요하다.
- 후보 앱의 데이터 경로가 로컬인지, 촬영 중 조작이 녹화와 오디오 세션에 영향을 주는지 확인하지 않았다.
- 별도 기기 기록과 영상의 시각 오차를 재지 않았고 표식 트랙의 리뷰어 표시 방식도 정하지 않았다.
- 조사 시점에 예약판매였던 Marker Maker의 출하·호환 상태는 동기 용도로 다시 검토할 때 확인해야 한다.
