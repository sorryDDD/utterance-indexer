# 008 · 옆방 음성 혼입

- **상태**: 열림

## 질문

이 회기의 참여자가 아닌 사람의 말이 녹음에 섞이는 조건을 어떻게 다룰 것인가.

제3자 발성은 잡음이 아니라 말이므로 발성 검출로 걸러지지 않고, 사람이 경계를 안정적으로 끊지 못하면 단일 채널 분리를 평가할 정답도 만들 수 없다.

## 남은 질문

- 참여자와 동시에 말한 제3자까지 포함한 실제 혼입량을 재는 방법이 없다.
- 제3자가 표시되지 않아 외부 음성으로부터 깨끗한 구간을 골라낼 수 없다.
- 벽을 통과한 음성의 고역 대 저역 에너지비는 정답을 만들 수 있는 다른 회기가 생기기 전까지 검정할 수 없다.
- 기확보 단일 채널 영상의 혼입을 어디까지 감수할지와 제3자가 둘 이상일 때의 화자 수 설정이 미정이다.
