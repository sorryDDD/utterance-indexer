# 001 · 프로젝트 경쟁력

- **상태**: 열림

## 질문

이 도구가 현존하는 언어치료 임상 도구들과 겨루어 만들 가치가 있는가. 있다면 어느 축에서인가.

만들 이유를 찾는 논의가 아니라 만들지 말아야 할 이유를 먼저 찾는다. 기존 도구 조합으로 충분하다는 결론이 나오면 그것도 답이다. 이 스레드는 구 `007` 자발화 분석 도구 현황을 흡수했으며 번호 `007`은 재사용하지 않는다.

## 남은 질문

- 긴 회기에서 발화를 찾는 시간이 실제 수요인지, 전사·부호화 시간과 분리해 확인하지 못했다.
- 리뷰 소요시간을 평가 지표로 도입하지 않았다.
- pyannote·Praat·VTC 등 대안 백엔드를 같은 정답 라벨로 견주지 않았다.
- 로컬 처리가 필수인 기관의 규모와 ELAN(EAF)·CHAT 내보내기의 실제 수요가 확인되지 않았다.
