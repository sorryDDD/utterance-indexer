# 010 · 임상 현장의 녹화 관행

- **상태**: 열림

## 질문

현장은 회기를 실제로 어떻게 찍으며, 그 관행이 이 도구의 입력·산출 전제를 어떻게 구속하는가.

## 관련 결정

없다.

## 남은 질문

- 스마트폰 한 대로 찍는 현장과 한국 사설 언어치료센터의 녹화 실태가 문헌에 잡히지 않았다.
- 관찰실의 기존 다채널 설비가 필요한 근접 대 원거리 채널을 실제로 제공하는지 확인하지 않았다.
- 평가 회기의 발화 비율이 자발화 표집 회기에도 성립하는지 알 수 없다.
- 책무성 목적으로 촬영한 녹화본을 이 도구가 다루는 것이 프로젝트 목적·금지선과 충돌하는지 판정하지 않았다.
