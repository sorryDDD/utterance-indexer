# 005 · 전사 기능의 위치

- **상태**: 열림

## 질문

보조 전사를 어디까지 할 것인가. 첫 실전에서 드러난 반복 환각은 도구의 한계인가 설정 문제인가.

전사는 맥락을 빠르게 파악하는 단서이며 임상가의 발화 여부와 의미 판단을 대신하지 않는다.

## 관련 결정

없다.

## 남은 질문

- 컨텍스트 차단 플래그 `-mc 0`을 기본값으로 넣을지 승인·구현되지 않았다.
- whisper 자체 VAD가 약한 발성을 놓치는지 정답 라벨로 재지 않았다.
- 임상가 참조 채널이 생길 경우 어느 트랙의 전사를 탐색 색인으로 삼을지 정하지 않았다.
- 목표 어휘 프롬프트와 반복 억제 대응을 시험하지 않았다.
