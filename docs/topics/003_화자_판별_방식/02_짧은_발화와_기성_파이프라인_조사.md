# 짧은 발화와 기성 파이프라인 — 문헌은 무엇을 말하는가

- **작성일**: 2026-08-23
- **작성자**: Claude Opus 5
- **근거**: 문헌 (웹 공개자료. 우리 데이터 실측 없음)

> 조사 요청에 임상 음성·전사 내용·대상자 정보는 포함하지 않았다. 일반 기술 용어로만 검색했다.

`01`의 실측이 우연인지, 아니면 구조적인 것인지 확인하기 위해 문헌을 조사했다.

## 1. 짧은 발화의 한계는 구조적이다

화자 검증 문헌은 이를 알려진 한계로 다룬다 — 짧은 발화에서는 **화자 표현이 어휘 내용에 오염된다**(Interspeech 2025, arXiv:2606.16115). 긴 발화를 전제로 학습된 임베딩일수록 그렇다.

최신 모델도 같은 전제 위에 있다. ReDimNet2는 VoxCeleb1-O에서 EER 0.287%로 최고 수준이지만 그 수치는 긴 발화 기준이다. WeSpeaker·CAM++·ERes2Net 계열도 마찬가지다.

**대상자의 발화는 대개 1초 안팎이다.** 임베딩 모델 교체로는 이 조건이 개선되지 않는다. `01`의 실측과 문헌이 같은 방향을 가리킨다.

## 2. 임상·아동 음성 벤치마크의 수준

임상 음성과 아동 음성이 포함된 **DIHARD-III**에서 모든 시스템이 **DER 18~26%** 범위에 있다. VoxConverse의 11%와 대조적이다. 조건이 어려우면 최고 시스템도 다섯 발화 중 하나를 틀린다.

## 3. 우리와 가장 가까운 연구

Xu 등(2026, arXiv:2601.17640)의 아동-성인 **역할 분리**다. 자폐 진단 상호작용 녹음에서 화자를 child/adult로 가르는 문제이며, 임상가-대상자 구도와 같다.

| 방식 | ADOS(깨끗한 녹음) DER | Playlogue(잡음 많음) DER |
|---|---|---|
| WhisperX zero-shot | 73.4% | 64.4% |
| Diarization-First (별도 화자 모델 → 세그먼트별 ASR) | 19.2% | **35.7%** |
| 제안 방식 (Whisper 기반 종단간, 파인튜닝) | **18.4%** | 40.6% |

읽어야 할 것이 셋이다.

- **기성 파이프라인을 조율 없이 쓰면 DER 64~73%다.** 우리 실패와 같은 결이며, 도구를 바꾸는 것만으로는 같은 자리에 도달할 뿐이다.
- 쓸 만한 수치(18~20%)는 **파인튜닝 후**에 나온다. 파인튜닝에는 라벨 데이터가 필요하다.
- **잡음 조건에서 성능이 급락한다.** 우리 녹음은 원거리·저음량(구간 RMS −43dB)이라 불리한 쪽이다.

중첩 발화도 확인됐다. 1초 중첩이 생기면 삭제 오류가 12.1%에서 28.2%로 뛴다. 촉진과 반응이 겹치는 임상 회기에서 그대로 문제가 된다. 같은 논문은 0.2초 미만 세그먼트를 평가에서 아예 제외했다 — 우리가 잡으려는 발성이 그 구간에 있다.

## 4. pyannote 도입 조건

`pyannote/speaker-diarization-community-1`은 CC-BY-4.0이고 완전 오프라인 실행이 가능하며 DER 11.2(VoxConverse)·11.7(AliMeeting)을 보고한다. 다만 **Hugging Face gated**여서 계정으로 조건에 동의하고 토큰을 발급해야 내려받을 수 있다(내려받은 뒤로는 오프라인).

실측하지 못한 이유가 이것이다. 토큰 확보는 작업지시자의 조치가 필요하다.

## 주장

1. 짧은 발화 조건을 **모델 교체로 해결하려는 시도를 접어야** 한다 — 문헌과 실측이 같은 결론이다.
2. 기성 파이프라인을 도입하더라도 **조율 없는 zero-shot 사용을 전제해서는 안 된다** — DER 64~73%다.
3. 잡음·원거리 조건을 개선하는 쪽을 **화자 알고리즘 개선보다 앞에 두어야** 한다 — 문헌상 성능 급락의 주 요인이다.
4. pyannote 실측을 하려면 작업지시자가 **Hugging Face 토큰을 확보하여야** 한다.
