# 003 · 화자 판별 방식

- **상태**: 열림

## 질문

대상자 구간과 임상가 구간을 무엇으로 가를 것인가.

어느 모델이 좋은가보다 어느 축으로 가를 것인가를 묻는다. 모델 교체, F0 특징, 분절, 참조 채널과 녹음 조건은 모두 이 물음에 답하는 후보 수단이다.

## 남은 질문

- F0 추정에 남은 주기성 게이트·RMS 게이트·64 ms 창의 성격과 실제 정확도가 확인되지 않았다.
- 단일 채널에서 대상자를 음색으로 찾는 경로와 임상가 참조 채널로 임상가를 걷어내는 경로 가운데 무엇을 주 경로로 둘지 승인되지 않았다.
- 참조 채널을 쓰더라도 구간 안의 동시 발화를 어떤 시간 단위로 다시 나눌지 정하지 않았다.
- 대상자에게 장비 착용을 요구하지 않으면서 근접 정보를 얻는 수단과 방에 흩은 다중 마이크 경로를 실측하지 않았다.
- pyannote community-1, 추가 라벨·홀드아웃, 두 기기 드리프트 보정과 외부 음성 혼입량이 미검증이다.
