# 회기 영상 발화 인덱서 사용법

긴 실습 영상에서 **누가·언제 소리를 냈는지**를 찾아, 그 지점 사이를 건너뛰며 들을 수 있게 하는
도구이다. 판단은 임상가가 귀로 하므로 이 도구는 전사기가 아니라 **탐색기**다.
전사는 맥락 파악을 돕는 보조 정보로만 붙는다.

- 실행: `src/speech_index.py`
- 화면: `src/reviewer_template.html` (건드릴 일 없음)

## 전제

처리는 **전 과정 로컬**에서 이루어지며 오디오·전사 결과는 외부로 나가지 않는다.

- `ffmpeg`, `whisper.cpp`(`whisper-cli`, `whisper-vad-speech-segments`), `numpy`(`.venv`)
- 전사 모델 `~/.cache/whisper.cpp/ggml-large-v3-turbo-q5_0.bin` (547MB)
- 발성 검출 모델 `~/.cache/whisper.cpp/ggml-silero-v5.1.2.bin` (864KB)

## 동작

1. 영상에서 16 kHz mono 오디오를 뽑는다.
2. **발성 구간을 검출한다** — 에너지 VAD 와 Silero VAD 를 각각 돌려 **합집합**을 취한다.
   놓치는 것이 오탐보다 훨씬 나쁘기 때문이다. 오탐은 리뷰어에서 한 번 눌러 넘기면 그만이다.
   합칠 때는 구간이 실제로 겹칠 때만 묶는다. 넓은 간격까지 묶으면 화자가 바뀌는 지점이
   한 덩어리가 되어 '누가'를 잃는다.
3. 구간마다 음향 임베딩(로그 스펙트럼 32밴드 평균·표준편차 + 기본주파수 F0)을 만든다.
4. **화자를 가른다.** k-means 로 화자 무리를 나눈 뒤,
   - `--target` 이 없으면 **가장 적게 말한 무리**를 대상자로 추정한다.
   - `--target` 이 있으면 참조 발화와 **가장 가까운 무리**를 대상자로 확정한다.
     참조는 무리를 고르는 데만 쓴다. 참조 한 조각에 직접 임계를 걸면 그 조각의 음소 특성에
     휘둘려 같은 화자의 다른 소리를 놓친다(실측에서 63%까지 떨어졌다).
5. whisper.cpp 로 전사해 각 구간에 텍스트를 붙인다(`--no-asr` 로 생략 가능).
6. 리뷰어와 인덱스를 낸다.

## 입력 형식

**형식 제한은 없다.** 스크립트는 확장자를 보지 않고 ffmpeg 에 그대로 넘기므로, ffmpeg 가 여는
컨테이너·코덱이면 모두 받는다 — `.mp4` `.mov` `.m4v` `.mkv` `.avi` `.MTS` `.webm` 등.
분석은 오디오만 쓰기 때문에 영상 코덱은 결과에 아무 영향이 없다(H.264 든 HEVC 든 동일).

다만 **리뷰어 재생은 별개 문제**다. 리뷰어는 브라우저의 `video` 태그로 원본을 그대로 트는데,
브라우저가 못 여는 코덱(HEVC, ProRes, 일부 MKV 등)이면 화면이 나오지 않는다. 이때는
`--proxy` 를 붙인다. 브라우저가 확실히 재생하는 480p H.264 사본을 만들어 그것을 물린다.
원본이 480p보다 작으면 해상도를 그대로 두고 코덱만 바꾼다.

```bash
./.venv/bin/python src/speech_index.py "/경로/회기영상.mov" --proxy --serve
```

프록시는 탐색(seek)도 빨라지므로, 회기 영상이 크다면 재생이 되더라도 붙일 만하다.

## 실행

```bash
cd ~/Workspace/utterance-indexer
./.venv/bin/python src/speech_index.py "/경로/회기영상.mp4" --serve
```

`--serve` 는 로컬 웹서버를 띄우고 브라우저로 리뷰어를 연다. **가장 확실한 방법이다.**
서버 없이 파일을 직접 열려면 `--serve` 를 빼고 안내된 `open` 명령을 쓰되, 브라우저가 영상을
재생하지 못하면 `--proxy` 를 붙여 다시 실행한다.

결과는 `영상폴더/speech-index-<영상이름>/` 에 쌓인다.

| 산출물 | 내용 |
| --- | --- |
| `reviewer.html` | **주 산출물.** 영상 + 타임라인 + 구간 목록 + 키보드 점프 |
| `index.md` | 대상자 구간 타임코드 표 |
| `subtitles.vtt` | 화자 표시 자막. IINA·VLC 등 기존 플레이어에 얹어 쓴다 |
| `segments.json` | 전체 구간 원자료 |

## 리뷰어 조작

| 키 | 동작 |
| --- | --- |
| `K` / `J` | 다음 / 이전 구간으로 점프 (필터가 켜져 있으면 대상자 구간만) |
| `Space` | 재생 / 정지 |
| `R` | 현재 구간 반복 |
| `1` `2` `3` `0` | 대상자 / 임상가 / 잡음 / 해제 라벨 |
| `F` | 대상자 구간만 보기 토글 |
| `,` / `.` | 0.5초 뒤로 / 앞으로 |
| `-` / `=` | 재생 속도 |

상단 타임라인은 전체 회기를 한눈에 보여준다. 주황색이 대상자 구간, 회색이 임상가 구간이며
아무 곳이나 클릭하면 그 시각으로 이동한다. 기본값은 **구간이 끝나면 자동 정지**이므로,
`K` 만 연달아 누르면 발화에서 발화로 건너뛰며 들을 수 있다.

## 권장 2단계 운용

1. 먼저 그냥 돌려 리뷰어를 연다. `K` 로 훑으며 진짜 대상자 발화에 `1`,
   아닌 것에 `2` 를 눌러 표시한다. 라벨은 브라우저에 자동 저장된다.
2. **라벨 내보내기** 버튼으로 `labels.json` 을 받아, 그것을 넘겨 다시 돌린다.
   표시해 둔 발화들이 참조가 되어 판별이 정확해진다.

```bash
./.venv/bin/python src/speech_index.py "/경로/회기영상.mp4" \
  --labels ~/Downloads/labels.json --serve
```

시각을 직접 지정해도 된다. 여러 번 줄수록 좋다.

```bash
--target "12:34-12:38" --target "24:03-24:06"
```

## 주요 옵션

| 옵션 | 기본값 | 용도 |
| --- | --- | --- |
| `--serve` | 꺼짐 | 로컬 서버로 리뷰어 열기 (권장) |
| `--proxy` | 꺼짐 | 브라우저용 저용량 480p 사본 생성. 재생·탐색이 느리거나 안 될 때 |
| `--target "MM:SS-MM:SS"` | 없음 | 대상자 참조 발화. 여러 번 지정 가능 |
| `--labels labels.json` | 없음 | 리뷰어에서 내보낸 라벨을 참조로 사용 |
| `--speakers N` | 2 | 영상에 등장하는 화자 수. 보호자가 함께 있으면 3 |
| `--sensitivity` | 0.25 | 낮출수록 작은 소리까지 검출. 발성이 약하면 0.15 |
| `--min-dur` | 0.12 | 이보다 짧은 소리는 버림. 짧은 발성까지 잡으려 낮게 잡아 두었다 |
| `--vad` | both | `energy` / `silero` 로 한쪽만 쓸 수도 있다 |
| `--pad` | 1.5 | 재생 시 앞뒤 여유(초). 선행 자극·촉진을 보려면 3 이상 |
| `--prompt "어휘"` | 없음 | 전사 유도. 회기 목표 낱말을 넣으면 해당 낱말 인식률이 오른다 |
| `--no-asr` | — | 전사 생략. 타임코드만 필요하면 훨씬 빠르다 |

## 성능·검증

5분 영상 기준 전사 포함 23초, 전사 없이 1초 미만. 90분 회기는 5분 안팎으로 예상한다.

검증은 실제 음성(whisper.cpp 예제 음원)을 피치 변형해 두 화자를 만들고, 짧은 대상자 발화
19개(0.4~1.2초)를 5분 타임라인에 심어 측정했다.

| 모드 | 발성 검출 | 대상자 분류 | 오탐 | 검토량 |
| --- | --- | --- | --- | --- |
| 자동(k-means) | 19/19 | 19/19 | 0 | 15초 (원본의 5%) |
| `--target` 1개 | 19/19 | 19/19 | 0 | 15초 |

## 한계

- 위 수치는 합성 음원 기준이다. 실제 회기는 잡음·중첩 발화·마이크 거리 문제가 있으므로
  **첫 회는 결과를 직접 확인하고 파라미터를 조정해야 한다.**
- 임상가와 대상자가 동시에 말한 구간은 한 구간으로 뭉친다.
- 두 화자의 음색이 비슷하면 무리 선택이 틀릴 수 있다. `index.md` 의 무리별 유사도를 보고,
  차이가 작으면 경고가 뜬다. 이때는 참조 발화를 늘린다.
- 전사는 조음이 불명료할수록 틀리고, 없는 말을 지어내기도 한다.
  **전사는 탐색 단서일 뿐이며 자발화 기록은 반드시 직접 듣고 작성한다.**
- Silero VAD 는 CPU 로 돌린다. 현재 빌드에서 GPU 경로가 크래시하기 때문이다(속도 문제는 없다).
