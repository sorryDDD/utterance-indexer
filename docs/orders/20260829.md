# 2026-08-29

## 완료 — v0.1 현행 성능 측정과 원리적 버그 수정 (Issue #2)

타스크 #1에서 확보한 정답 라벨로 현행 파이프라인을 처음 채점하고, 코드와 설계 근거만으로 잘못임이 분명한 두 항목을 고친 뒤 같은 기준으로 다시 측정했다.

**채점 기준을 먼저 동결했다.** 정답 길이의 15%를 초과해 겹치면 적중으로 보고, `covered` 밖은 제외하며, 대상자 검출·조건부 화자 배정·짧은 발성·오탐 총량·임상가 누출·`E` 단독과 `f0=0` 반사실·합집합과 Silero 단독 짝비교를 한 하니스에서 계산한다. 실제 라벨과 산출물은 저장소 밖에 두고 합성 JSON 열 범주로 하니스 자체를 검증했다.

**현행 합집합은 대상자 검출 84/84(100%)를 달성했지만 화자 판별은 대상자 후보 23/69(33.3%), 임상가 누출 63/165(38.2%)였다.** Silero 단독은 대상자 65/84(77.4%)만 검출해 재현율 우선 목표에 맞지 않았다. 합집합의 오탐 총량은 68개·52.36초였고 `E` 단독을 제거하면 대상자 재현율이 88.1%로 떨어져 게이트로 쓸 수 없었다.

F0 탐색을 60–600 Hz로 넓히고 지역 최댓값 후보와 옥타브 상태 기록을 넣었다. 참조 발화가 없는 기본 경로에서는 구간 수가 아니라 총 발화 시간이 가장 짧은 무리를 대상자로 고르게 했다. 합성 250 Hz·500 Hz·무음과 무리 선택 원리 사례가 모두 통과했다.

수정 후 합집합의 대상자 검출과 오탐 총량은 그대로였고, 대상자 후보는 51/69(73.9%)로 올랐다. 임상가 누출도 104/165(63.0%)로 늘었다. 전체 1760개 중 F0 수정으로 무리 번호가 바뀐 구간은 2개뿐이어서 개선의 직접 원인은 총 발화 시간 선택 기준이었다. **재현율은 높아졌지만 화자 판별 문제가 해결된 것은 아니다.**

작업지시자는 단일 편향 표본에 맞춘 임계 튜닝을 하지 않고 추가 라벨·홀드아웃 검증을 우선하며, 녹음 조건·아키텍처 변경은 별도 승인 타스크로 다루기로 판정했다. 최종 결과보고서는 `docs/report/task_m010_2_report.md`다.

원격에는 `devel`까지만 반영하고 Issue #2는 닫지 않는다. `main` 통합·태그·브랜치 삭제도 하지 않는다.
