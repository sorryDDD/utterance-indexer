## 3. 결정 이관

기존 색인의 `채택` 23행을 1:1로 옮기지 않았다. 실제 승인 기록을 대조하여 같은 선택은 합치고, 독립적으로 뒤집을 수 있는 선택은 나누었다.

| 결정 | 내용 | 주된 승인 근거 |
|---|---|---|
| `D-001` | 화자 판별 성과를 대상자 후보 성공과 임상가 혼입으로 함께 판정 | 타스크 #2 단계 1·2 |
| `D-002`~`D-005` | VAD 합집합 유지, `E`·`f0=0` 게이트 제한, 오탐 총량의 해석 | 타스크 #2 단계 1 |
| `D-006` | 대상자 무리를 총 발화 시간으로 선택 | 타스크 #2 단계 1·2 |
| `D-007`~`D-008` | F0 교정 표지의 진단 한정과 배제 게이트 금지 | 타스크 #2 단계 2 |
| `D-009`~`D-010` | v0.1 상류를 화자 판별로 이동, 실제 잡음 비율은 사람 판정 | 타스크 #6 단계 5 |
| `D-011`~`D-013` | `other_voice`, 무라벨 의미, 잦은 혼입에서 표시 의무 면제 | 타스크 #1 동결 변경·마감 |
| `D-014` | F0 탐색 상한을 600 Hz로 설정 | 타스크 #2 단계 1·2 |

결정으로 옮기지 않은 대표 항목은 다음과 같다.

- 현행 화자 판별이 실전에서 작동하지 않는다는 것은 **실측 발견**이다.
- 알고리즘 수정 전에 정답 라벨을 확보한다는 것은 이미 끝난 **일회성 실행 순서**다.
- F0를 고친 뒤 같은 라벨로 재측정한다는 것은 완료된 **작업 지시**라 제외했지만, 그 작업에서 승인된 되돌릴 수 있는 파라미터 선택인 60–600 Hz 탐색 범위는 `D-014`로 등재했다.
- 제3자 혼입량을 거친 덩어리 표시나 역산으로 잰다는 안은 역산이 총량을 답하지 못해 **현재 방법이 확정되지 않았다.**

장부 도입 전에 프로젝트 개시 시점에 정해져 `AGENTS.md` §1에만 남은 기술 스택·금지선의 승인 경위는 소급해 꾸미지 않았다. 결정 장부의 머리에 이 이관 경계를 명시했다.

각 안내문은 `질문 · 상태 · 관련 결정 · 남은 질문` 이외의 절을 두지 않는다. 미승인 추천은 기존 번호 글에 그대로 남았으며 판정 대기열로 다시 만들지 않았다.

`002`의 닫힘은 다시 감사했다. 중심 질문인 첫 실전 실패의 원인 규명은 타스크 #6에서 끝났고, 옛 미해결 셋은 각각 Issue #4와 `003`·`004`, `D-010`, `003`의 구간 내 재분할 질문으로 이관되어 원문 `002#01`과 함께 추적된다. 이 기준을 한 사례의 묵시적 판정으로 두지 않도록 규약에는 **중심 질문의 해결과 모든 잔여 항목의 해결 또는 소유자 이관**을 닫힘 조건으로 명시했다.

## 5. 규약과 권위 구조

작업 규약 §0에 `docs/decisions.md`를 프로젝트 결정의 정본으로 추가했다. `AGENTS.md`는 프로젝트 고유의 **현행 상태·유효한 규칙**, 결정 장부는 **무엇을 승인했는가**를 담당한다. 따라서 결정의 `유효` 상태는 대체되지 않았다는 뜻이지 구현 완료를 뜻하지 않는다.

스레드 규칙에서는 강제 `## 주장` 절, 「오간 주장」 표, `미검토 / 채택 / 기각 / 조건부 / 정정됨 / 보류` 상태를 폐지했다. 기존 글 불변·번호 불변·근거 등급은 근거 추적에 값이 있으므로 유지했다.

답변 각주 규칙도 새 구조에 맞췄다. 논의 글은 핵심 내용·근거·인용 시점을, 결정은 식별자·결정문·상태·승인 시점을 함께 밝힌다.

결정 표제는 `D-NNN-short-english-slug`로 바꾸고 사람이 읽는 한글 제목을 별도 필드로 두었다. 제목이 바뀌어도 영문 슬러그는 고정되므로 안내문은 한글 헤딩 슬러그에 의존하지 않고 결정 항목으로 바로 이동한다.
