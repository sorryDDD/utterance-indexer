## 기준선 보존과 재현 확인

라벨 후보와 현행 산출물은 각각 하나로 대응됐다. 라벨 집계는 타스크 #1 결과보고서와 같았다.

| 항목 | 확인값 |
|---|---:|
| 들은 범위 | 776.51초 |
| 대상자 | 84개 |
| 임상가 | 180개 |
| 보류 | 3개 |
| 제3자 | 0개 — 표시하지 않은 것 |

| 임상가와 겹친 대상자 | 15개 |

첫 동작으로 라벨과 현행 `segments.json`을 권한을 제한한 새 임시 폴더에 복사했다. 기존 파일은 삭제·이동·덮어쓰기하지 않았다.

같은 원본에 현재 `speech_index.py`를 기본값·`--no-asr`로 다시 실행했다. 보존 산출물과 재실행 합집합은 **전사 `text`를 제외한 모든 채점 필드가 같았고**, 아래 지표도 전부 일치했다. 전사를 생략한 새 실행의 `text`가 빈 것이 유일한 차이다. 따라서 보존 산출물과 재실행 합집합을 같은 현행 기준선으로 확정할 수 있다.

기준선의 추적 기준은 `devel`과 `local/task2`가 갈라진 커밋 `ff697e1`의 `src/speech_index.py`다. 단계 1에서는 이 파일을 고치지 않았다.

## 채점 기준

- 정답 길이의 **15%를 초과**해 겹치는 검출 구간이 하나라도 있으면 적중. `tests/regression.py`와 같은 기준이며 정확히 15%는 비적중이다.
- `covered` 밖은 제외하고, 경계를 걸친 검출 구간은 안쪽 부분만 집계.
- 대상자 검출과 화자 후보 성공을 분리. 화자 판별은 임상가와 겹친 대상자 15개를 제외한 69개 위에서 측정.
- `unsure`는 대상자 중심값에서 제외하고 대상자+보류 보조값에 포함.
- 참여자 라벨과 전혀 겹치지 않는 검출 구간의 개수와 합집합 시간을 오탐 총량으로 집계. 제3자 미표시 때문에 잡음량이라고 부르지 않음.
- 여러 실행을 같은 라벨에 짝지어 대상자별 「둘 다 / 앞만 / 뒤만 / 둘 다 놓침」을 집계.

하니스 `--self-test`가 범위 자르기, 15% 경계, `unsure`, 짧은 발성, 임상가 중첩 제외, 검출·화자 실패 분리, 오탐 시간 합집합, `E`·`f0=0` 반사실, VAD 짝비교, 잘못된 스키마 거부의 열 범주를 합성 JSON으로 검증한다.

대상자별 짝비교는 둘 다 적중 65개, 합집합만 적중 19개, Silero만 적중 0개, 둘 다 놓침 0개다. **Silero 단독은 대상자 22.6%를 놓치므로 재현율 우선 원칙과 맞지 않는다.**

### 오탐 총량

| 설정 | 채점 범위 안 검출 | 검출 시간 | 오탐 총량 | 오탐 시간 |

| 표지 | 구간 | 참여자와 비중첩 | 일괄 제거 뒤 대상자 재현율 | 하락 |

## 화자 판별 기준선

합집합은 화자 판별 대상자 69개를 모두 검출했지만 대상자 후보로 남긴 것은 **23개(33.3%)**다. 0.5초 미만 화자 판별 대상 13개에서는 4개(30.8%)다.

대상자·보류와 겹치지 않은 임상가 165개 중 164개가 검출됐고, 임상가 발성 63개가 대상자 후보로 혼입됐다. 전체 임상가 기준 혼입률은 38.2%, 검출분 조건부 혼입률은 38.4%다.

### 구간 수 기준과 총 발화 시간 기준

| 무리 | 전체 구간 수 | 전체 발화 시간 | 대상자로 가정했을 때 대상자 성공 | 임상가→대상자 후보 혼입 |
|---|---:|---:|---:|---:|
| 0 | **661개** | 2627.70초 | 23/69 (33.3%) | 63/165 (38.2%) |
| 1 | 1099개 | **1829.76초** | 51/69 (73.9%) | 104/165 (63.0%) |

현행 구간 수 기준은 0번을 대상자로 고른다. 실행계획의 총 발화 시간 기준은 라벨을 보지 않고도 1번을 고르며, 라벨 진단에서도 그 무리가 대상자를 더 많이 담았다. 따라서 무리가 완전히 무의미한 것은 아니고 **무리를 고르는 규칙이 재현율 우선 목표와 반대로 작동했다.**

총 시간 기준은 대상자 후보 성공을 높이는 대신 임상가 발성의 대상자 후보 혼입도 늘린다. 이 도구는 재현율을 우선하지만 리뷰 부담을 무시하지 않으므로, 단계 2에서 수정한 뒤 두 값을 함께 재야 한다.

Silero 단독에서도 구간 수와 총 시간 기준이 반대 무리를 고르지만, 대상자 후보 성공은 각각 36.2%와 43.5%이고 검출 단계에서 이미 대상자 19개를 잃는다. Silero 단독 채택 근거가 아니다.
